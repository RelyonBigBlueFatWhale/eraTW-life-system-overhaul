# eraTW 生活系统大修  v2.32.3（增量补丁）

> 适用基线：`EraTW-Magic_DLC-update_base`（最新测试版，含旧生活系统大修 + 魔法DLC 整合）
> 本补丁为增量：将文件按相对路径覆盖到游戏根目录即可。

## 本版更新

### v2.32.3 独立代码审阅问题修复
- **鸭蛋不能孵化**：孵化器蛋循环上界漏掉 714
- **进度条恒空**：`@生活系统_进度条` 追加的是空串（蜂箱 / 鱼塘界面都受影响）
- **鱼塘菜单误灰显**：`[7] 放入鱼` / `[8] 喂食` 被一同灰掉
- **开荒出的畝不自动洒水**：DLCEVENT 上界仍用 `1+畑拡張`
- **天堂制造**：补 `RETURN 1`，并把停用的旧双模式段标注为历史设计

### v2.32.2 回灌上游审阅修复
- **第 5 口鱼塘每日结算必崩**：鱼塘 14 个按塘索引的数组 5 → 6（塘号 1-based）
- **家具屋三个 bug**：917 打捞具没进列表 / 第 4 个酒桶与第 4 个蜂箱订不了 / 酒桶与打捞具的制作参数被错位（套用了别的家具）
- **绯红之王推进不足**：改为直接跳到该酒醸造日数，长酿与咸鸭蛋都能一次完成
- 补蜂箱的作成台词、说明文与「再订一个蜂箱」

### v2.32.1 修复（bugfix）
- **酒桶0 酿造时间归零**（玩家报告）：酒桶菜单顶部清空备份槽的 `SIF` 改为 `IF/ENDIF`（`SIF` 只保护紧随其后的 1 行，第二行「天数=0」变成无条件执行）
- **授粉标记数组越界**（玩家报告）：养蜂 3 处畝循环下标改为 0-based（`0..畝数()-1`），修正 畝数()=240 时访问下标 240 越界，同时补回此前漏掉的第 0 畝
- **鱼塘「取鱼肉」无效**：同类 SIF 双行陷阱导致 `RETURN 1` 无条件执行，取鱼肉永远拿不到鱼
- **鱼塘单鱼槽位**：同类陷阱导致选中本页不存在的槽位时直接退出鱼塘界面
- **授粉标记未随植株重置**：单块播种 / 一键播种时清除该畝遗留的授粉标记——原写法下 `mark=1` 的地块此后永远不再被授粉，`mark=2` 会给新株白送增产

### 鱼塘系统重做（按个体储存 + 拟真繁殖）
- 每条鱼独立记录「鱼种 / 长度 / 性别」，不再按塘统一归类；单条鱼可分别收回隙间、取鱼肉、卖掉、打捞鱼籽
- 性别：雌/雄（未成熟时隐藏）；现实具变性能力的鱼种（石斑鱼、鲫鱼、鳗鱼）与虚构鱼可在性别失衡时转换性别，但不能自我授精（至少 2 条）
- 集中产卵：按鱼种产卵季节（春/夏/秋/冬），**每季第 15 天**同日产卵（跨鱼塘同步）
- 受精：产卵期结束时有雄鱼才受精进入孵化；无雄鱼则卵消失
- 孵化结束：鱼苗直接**填满鱼塘剩余槽位**
- 界面重做：一览+分页详情（每页 5 条）、 进度条、请求鱼塘整行高亮标注
- 完成请求：无进行中请求时**灰显不可用**

### 蜂箱界面重做
- 一览显示**今日加成（季节 + 天气）**、 进度条
- 空箱只显示「放入蜂王」；详情显示存蜜/进度条
