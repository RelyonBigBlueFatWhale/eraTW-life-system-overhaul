## 本分支包含的修复（10 个文件）

### A. 玩家报告的两个 bug
1. `ERB/DLC/生活系统大修/生活系统_酿酒.ERB` — `$酒桶_LOOP` 顶部 `SIF` 只保护 1 行，`酒桶_天数:0 = 0` 每轮无条件执行
   → 从其它酒桶切回酒桶0时备份的发酵天数被清零（**酒瓶0酿造时间归 0**）。改 `IF/ENDIF`。
2. `ERB/DLC/生活系统大修/生活系统_养蜂.ERB` — 3 处畝循环写成 `FOR LOCAL, 1, 畝数()+1`（畝下标是 0-based）
   → 漏掉第 0 畝，且畝数()=240 时越界（**授粉标记数组越界**）。改 0-based。

### B. 同批排查出的静默 bug
3. `ERB/fromEN/Custom_Commands/ADD_CUSTOM_COM515 鱼塘.ERB` — 两处 `SIF` 双行陷阱：
   「取鱼肉」永远拿不到鱼；选中本页不存在的槽位时直接退出界面。
4. `ERB/DLC/生活系统大修/生活系统_COM418.ERB` + `生活系统_种地.ERB` — 播种时清除该畝遗留的
   `生活系统_授粉标记`（标记按「同株一次」设计，原实现下 mark=1 会让该畝**永不再被授粉**）。
5. `ERB/DLC/生活系统大修/生活系统_养鸡.ERB` — 孵化器蛋循环上界 714 → 715（**鸭蛋进不了孵化器**）。
6. `ERB/DLC/生活系统大修/生活系统_鱼塘.ERB` — `@生活系统_进度条` 追加空串导致**进度条恒为空**，改 ■/□。
7. `ERB/fromEN/Custom_Commands/ADD_CUSTOM_COM515 鱼塘.ERB` — 灰显只作用于 `[9] 完成请求`。
8. `ERB/DLC/DLCEVENT.ERB` — 自动洒水/成熟提示上界改用 `生活系统_畝数()`（开荒出的畝此前不参与）。
9. `ERB/DLC/生活系统大修/生活系统_魔法联动.ERB` — `@生活系统_天堂制造` 补 `RETURN 1`，停用的双模式段标注为历史设计。
10. `ERB/コマンド関連/COMF/日常系/酒関連.ERB` — **恢复上游整合时丢失的鲟鱼卵→鱼子酱链**：
    develop 的 `生活系统_菜单.ERB` 仍写着「鲟鱼卵入酒桶腌成鱼子酱」，但 `酒関連` 里
    既无 `ADDITIONS` 的鲟鱼卵、也无 `@酒データ120` —— 整合（`299e4def`）时整段丢失，
    鱼塘打捞出的鲟鱼卵因此没有任何用途。本文件恢复 ADDITIONS 条目、`ITEM`/`QUANTITY` 段
    与 `@EXIST_酒データ120`/`@酒データ120`（清酒中 14 天 → 鱼子酱，醸造数 1）。
