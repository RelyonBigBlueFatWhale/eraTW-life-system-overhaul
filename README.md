# eraTW 生活系统大修  v2.32.0（增量补丁）

> 适用基线：`EraTW-Magic_DLC-update_base`（最新测试版，含旧生活系统大修 + 魔法DLC 整合）
> 本补丁为增量：将文件按相对路径覆盖到游戏根目录即可。

## 本版更新

### 鱼塘系统重做（按个体储存 + 拟真繁殖）
- 每条鱼独立记录「鱼种 / 长度 / 性别」，不再按塘统一归类；单条鱼可分别收回隙间、取鱼肉、卖掉、打捞鱼籽
- 性别：雌/雄（未成熟时隐藏）；现实具变性能力的鱼种（石斑鱼、鲫鱼、鳗鱼）与虚构鱼可在性别失衡时转换性别，但不能自我授精（至少 2 条）
- 集中产卵：按鱼种产卵季节（春/夏/秋/冬），**每季第 15 天**同日产卵（跨鱼塘同步）
- 受精：产卵期结束时有雄鱼才受精进入孵化；无雄鱼则卵消失
- 孵化结束：鱼苗直接**填满鱼塘剩余槽位**
- 界面重做：一览+分页详情（每页 5 条）、 进度条、请求鱼塘整行高亮标注
- 完成请求：无进行中请求时**灰显不可用**

### 蜂箱界面重做
- 一览显示**今日加成（季节 + 天气）**、 进度条
- 空箱只显示「放入蜂王」；详情显示存蜜/进度条

### 生活质量提升新增
- **水龙头**：仅厨房（原版可放置酒虫处）可打普通水
- **倒掉饭菜**：携带料理时可用，立即清空携带的料理（自定义指令 516）

### 学习与教育系统改进
- 整合成人再教育 / 悟性系统到生活系统大修设置界面
- 同伴经验：授课经验同步给予同行少女（含体力/气力扣除与料理随机回复同步）
- 学费档位：不变 / 1.5 / 2（按同行人数加算）

### 其他
- 活跃的妖精集团整合进生活质量提升
- 采集蜂王保底（30% 基础概率，连续 4 次未出必得）
- 天堂制造可加速鱼塘建造
- 巧克力转换修复（QOL 数据库刷新；调和列表可见）
- 武道大会排序修复、料理委托高亮修复（仅持有委托时亮蓝）

## 安装
将本补丁内所有文件按相对路径覆盖到游戏根目录。
