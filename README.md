## 隙间渔获（钓鱼2.0）

- **渔获与道具解耦**：上鱼时不再直接换算成「鱼/好吃的鱼」，而是把鱼种+个体尺寸存入
  `QOL_FISH_INSTANCE` 实例表（随存档保存，复用钓鱼重构 qol_fish 的数据层与 `SAVE_DTS` 注册）。
- **入口**：游戏主菜单 → [114] 隙间渔获；或 行动菜单 → [自定义] → 隙间渔获。
- **鱼情报详情页**：点击隙间中的一条鱼 → 查看尺寸评价（按该鱼种体型区间+绝对尺寸、上色）、
  稀有度星级（上色）、特征描述；下方【获取鱼肉】需二次确认后才转道具。
- **获取鱼肉**：在隙间中选择鱼种 → 单条 / 该种全部 → 转成道具 鱼(707)/好吃的鱼(708)，1尾=1道具。
- **容量**：基础 30，满员时新鱼自动转回直给道具并提示；消耗「收藏隙間」(ITEM:400)×10 → +1，上限 90。
- **边界**：仅「钓鱼系统」开关开启时接管渔获；关闭时与上游行为完全一致。

## 读书系统改造（v2.1.3）

- 需先在「生活系统大修设置 → [5] 读书系统」开启。
- 读**实用书** → 展开子菜单「想找哪方面的书？」：人际沟通/烹饪菜谱/垂钓指南/荒野求生/调合配方/伐木心得/耕种教材（**种地开关关闭时耕种教材完全不显示**），选中后直接进入对应经验判定。
- **学到时展示一段真实书籍摘录**（《论语》《菜根谭》《随园食单》《钓客清话》《本草纲目》《化学实验指导》《考工记》《齐民要术》随机一小段）。
- **等级化学习判定**：学到概率随对应技能等级递减 `P=(上限-等级)/(上限-等级+3)`，等级达到上限一无所获；**文学书**同样套用（按教養等级）。上限与引擎一致 `6+N×MAGIC_DLC_等级重置`（兼容魔法补丁）。
- 门控：由独立开关「读书系统」控制；关闭时读书行为与上游完全一致。

## 魔法版联动（v2.1.5）

- 开关：生活系统大修设置 → [9] 魔法版联动内容（需已启用魔法补丁 MAGIC_DLC）。
- **天堂制造**（TSlv5，ITEM 984）：使用绯红之王 酿酒/加速孵化/弹幕战 时 15% 获得 1 点熟练度，熟练度 3 解锁。
  - 发动后选择目标：**对自己** → 时间压缩（非性爱系指令执行时间改为 1 分钟，就寝/次日解除）；**家具屋老板**（制作家具中）→ 立即完工（FLAG:家具作成残り=0）。
  - 非性爱系 = 排除 0-199 / 313-330 / 350-361 / 700-799 的标准性爱区间。
- 对魔法补丁文件仅做最小、明确标注的挂钩（注册/分发/熟练度）。

## 大量警告修复（v2.1.7）

修复重新启动游戏时控制台出现的 12 条警告（均来自本补丁文件，重启后不再出现）：

- `生活系统_魔法联动.ERB`：事件函数（`@EVENTCOM`/`@EVENTCOMEND`）中的 `#LOCALSIZE`/`#LOCALSSIZE` 会被引擎忽略并告警 → 已删除（事件函数不适用局部变量声明）。
- `生活系统_武道大会.ERB`：一维/角色数组带变量下标时未加括号导致「参数过多」→ 统一改为 `RESULT:(LOCAL:2)`、`CFLAG:(LOCAL:5):面識`、`TCVAR:(LOCAL:5):弾幕勝負不能`、`CALLNAME:(LOCAL:5)`（与代码库既有写法一致）。
- `生活系统_养鸡.ERB`：孵化加速处残留一行残缺代码（`孵化槽_剩余天数` 与 `ITEM:绯红之王 --` 挤在同一行）导致「表达式异常」→ 已删除该残缺行。

验证：修复后引擎启动无任何警告（`debug/console.log` 仅剩正常的 TALENT 表转储）。

## 修复（v2.1.8）

- **天下第一武道大会按钮不显示**：之前只判断据点模式地点「神社境内」(20)，开启「幻想乡大地图」出行到神社时实际在**外出地图模式**，地点编号为新式「P2境内」(2)，导致按钮不出现。现已同时接受两种模式的地点（`神社境内 || P2境内`）。
- **「天堂制造」未发现翻译**：`ITEMNAME_TR(984)` 需在 `plugins/tw_csv_chs.xml` 翻译表查「天堂制造」，此前未注册，道具菜单/道具解说会报 `※未能找到天堂制造翻译`。已加入 `<k>天堂制造</k><v>天堂制造</v>`（与魔法DLC 既有魔法条目同格式，重启游戏后 TR_DB 自动重建生效）。
