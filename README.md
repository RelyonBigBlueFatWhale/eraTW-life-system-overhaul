### 生活质量提升（主菜单 [9]  子菜单）
- 读书系统（自选分区/等级化学习）
- 料理委托改善（委托17 口味旁标注最佳菜谱；做菜时最高匹配菜谱黄色高亮）
- 巧克力转换（调和配方 Lv1：黑雷神巧克力1巧克力1；高級巧克力1巧克力3）

### 其它修改
- 主菜单重排（分组：生产养殖/联动拓展/体验便捷，连续编号 1~13，入口清屏）
- 家具屋新增 蜂箱（5天/3天）、鱼子酱打捞具 打造
- 酒桶新增 鲟鱼卵鱼子酱（腌制14天，酒数据120）
- 采集获得蜂蜜时有 30% 概率发现蜂王；鱼子酱可直接食用（恢复体力/气力）
- 新道具：鲟鱼卵/鱼子酱/蜂王/彼岸花蜜；新家具：蜂箱/鱼塘/鱼子酱打捞具；新素质：熊之友（TALENT 505）

将本补丁内所有文件按相对路径覆盖到 `H:\ERAworkspace`（游戏根目录），覆盖对应 ERB/CSV/plugins 文件即可。
（补丁只含增量，基底已有的 v2.1 内容无需重复覆盖。）
