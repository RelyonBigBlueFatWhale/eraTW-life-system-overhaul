## 简介

「生活系统大修」为 eraTW（东方文字冒险游戏）注入一套完整的日常经营玩法：
四个互相独立、可随时启停的子系统，覆盖**养殖、农耕、酿酒、垂钓**四条生活产业链。
所有子系统由「DLC 设置」菜单统一管理，**关闭时完全恢复原版逻辑**，不影响原版游玩与继承更新。

> **基线**：本补丁基于 [eraTW画蛇又添足（eratw-sub-modding）](https://gitgud.io/era-games-zh/touhou/eratw-sub-modding) develop 分支（e9220932）。
> **架构**：上游本体文件保留原样，仅入口处添加「开关 → 转入 DLC 实现」的 JUMP 分支；
> 全部增强逻辑位于 `ERB/DLC/生活系统大修/`，开关关闭时本体行为完全不变，便于 rebase 上游。

## 功能特性

### 🐔 养鸡系统
- **鸡舍扩建**（家具 911）：Lv1=5 间、Lv2+=8 间饲育小屋
- **孵化器**（家具 912）：可孵化卵、鸭蛋乃至**龙蛋**（龙蛋需漫长岁月，可用 TSP / 绯红之王加速）
- **自动抚摸机**（家具 913）：每日自动提升好感
- **分档抚摸互动**：好感低/中/高显示不同文本，龙类以彩色文本彰显稀有
- **饲料箱**：存量、等级、每日消耗一体的管理界面；[收集产物] 一键收蛋
- **产业链**：养鸭产鸭蛋 → 调合 → 腌制 → 咸鸭蛋

### 🌾 种地系统
- **育苗设施**（家具 908）：采集素材育成种子，成材稀有度决定等级与熟期翻倍
- **温室大棚**（家具 909）：无视季节种植；**隙间耕地**（910）：畝数上限 240
- **新种子作物**：山菜、药草、菌菇、浆果等 22 种，浆果/菌菇可再收一茬
- **开荒指令**：每日一次，开垦额外耕地（体力/气力消耗随耕种等级递减）
- **花屋解锁**：模组苗初始不在花屋出售——育苗获得后当晚结算事件解锁出售并获酬金
- **耕种天赋**：Lv3 / Lv6 二选一（催熟·丰收 / 沃土·双收）

### 🍶 酿酒系统
- **橡木酒桶**（家具 914）：最多 5 个，**酒桶 0 = 原版酒虫**，翻页式切换，每桶独立完成酿酒全部工作
- 完整发酵链：水 → 添加物 → 清酒/浊酒/……；TSP 加速、绯红之王跳过
- **咸鸭蛋腌制**：清酒 + 20 个待腌制咸鸭蛋 → 14 天腌成（需养鸡+酿酒同时开启）

### 🎣 钓鱼系统
- 以钓鱼小游戏取代原版判定：浮漂下沉提竿 → 拉锯战选对方向削减鱼体力
- 钓鱼等级越高反应时间越长，技艺精湛时正确方向高亮

## 安装

1. 下载 `生活系统大修补丁.zip`
2. 解压后，将 `ERB`、`CSV`、`plugins` 三个文件夹**覆盖**到游戏根目录
   （与 `Emuera_skiaV10_x64.exe` 同级，zip 内目录结构与原版一致）
3. **若已存在旧版 `plugins/qol_data.db`，请先删除**——游戏启动时会自动重建数据库（含新增料理/调合配方）

```
游戏根目录/
├── ERB/
├── CSV/
├── plugins/
└── Emuera_skiaV10_x64.exe
```

## 启用

游戏内：**DLC 设置 → [69] 生活系统大修**，进入主菜单：

```
[1] 养鸡系统    [2] 种地系统
[3] 酿酒系统    [4] 钓鱼系统
```

各子系统独立启停；咸鸭蛋产业链需要养鸡与酿酒**同时开启**。

## 玩法指引

| 系统 | 入门路径 |
|---|---|
| 养鸡 | 家具屋打造鸡舍扩建 → 购买家畜/孵化蛋 → 饲料箱喂食 → 收集产物 |
| 种地 | 先去图书馆寻找耕种基础教程 → 育苗设施育成种子 → 菜园种植 → 成熟收获 |
| 酿酒 | 家具屋打造橡木酒桶 → 水汲み → 添加物发酵 → 取出成品 |
| 钓鱼 | 持有钓竿 → 浮漂下沉时提竿 → 拉锯战胜出 |

## 兼容性与存档

- 全部新增变量均为独立 SAVEDATA，**旧存档可继续使用**（框架版本迁移自动处理）
- 引擎加载验证：Debug 模式 **0 警告**
- 本补丁不包含运行时生成的 `qol_data.db` 与 `sav/` 存档数据

## 开发说明

- 各子系统为**独立文件、互不耦合**，可单独移植/维护
- 新功能请遵循既有约定：
  - 变量声明写入 `0_生活系统_变量.ERH`
  - DLC 逻辑放入 `DLC/生活系统大修/`，原位文件只做开关明确的调用分支
  - 物品查询使用原语名（`ITEMNAME`），勿用翻译名（`ITEMNAME_TR`）
